# 타임지그 — 사용 글꼴 라이선스 정리

앱에서 쓰는 모든 글꼴은 **Google Fonts**(`fonts.googleapis.com`)에서 제공하는
오픈소스 글꼴입니다. 로컬에 글꼴 파일을 포함(재배포)하지 않으며, 런타임에
CDN으로 불러와 화면 표시 및 이미지(PNG) 렌더링에 사용합니다.

- 대부분 **SIL Open Font License 1.1 (OFL)**, 일부 **Apache License 2.0**
- 두 라이선스 모두 **상업적 사용 / 앱 출시 / 결과물(이미지) 배포** 허용
- OFL은 글꼴로 만든 **문서·이미지 결과물에 아무런 제한이 없음** → 잠금화면 PNG 자유 사용
- OFL이 금지하는 것은 "글꼴 파일 자체의 단독 판매"뿐 (본 앱과 무관)
- 글꼴 파일을 직접 재배포하지 않으므로 라이선스 텍스트 동봉 의무는 사실상 없음
  (추후 오프라인용으로 글꼴을 앱에 내장할 경우, 해당 글꼴의 OFL.txt를 함께 포함하면 됨 — OFL 허용)
